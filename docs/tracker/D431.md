# D431 — Outbound Campaign Dashboard

## Summary
The full outbound pipeline works (campaign_leads → dial-out/scheduled-callbacks → Ultravox → Twilio → call_logs → /completed webhook). But there is no dashboard UI for clients to manage campaigns. No lead import, no campaign creation, no dial history, no disposition analytics.

## Required
- Campaign list page: name, lead count, dialed, answered, VM, no-answer
- Lead import: CSV upload or manual entry
- Lead queue: bulk dial, schedule callbacks, mark DNC
- Campaign analytics: dial success rate, avg duration, disposition breakdown
- Personality selection per campaign (ties to D430)
- Call window scheduling per campaign (time zone aware)
- Scheduled callbacks visible in dashboard with retry count

## Acceptance
- Client can create a campaign with a name
- Client can import leads via CSV
- Bulk dial from lead queue uses client's outbound config + selected personality
- Dashboard shows dial history with dispositions
- Scheduled callbacks are visible and can be cancelled
