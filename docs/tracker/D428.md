# D428 — Demo Agent Knowledge: load real product knowledge into RAG

## Summary
The `unmissed-demo` agent (Zara, slug=unmissed-demo) answers product questions by relying on its system prompt + a `queryKnowledge` tool. But the `knowledge_chunks` table for this client has no approved chunks about End Voicemail itself — product features, pricing, setup instructions, carrier forwarding codes, niche support, competitor comparisons, etc. When a caller asks "how do I set this up on Bell" or "what happens after 50 minutes," the agent can't answer from knowledge.

## Required
- Load approved `knowledge_chunks` for `unmissed-demo` covering:
  - Product overview: what End Voicemail does
  - Pricing: $119/mo Pro, $29/mo Trial, what's included
  - Setup: call forwarding codes for Rogers/Fido, Bell/Virgin, Telus/Koodo, Freedom, SaskTel
  - Voicemail removal: how to disable carrier voicemail per carrier
  - Carrier compatibility: what works, what has blockers
  - Feature list: booking, SMS, Telegram, email alerts, transfer, outbound campaigns
  - Niche support: which niches have templates, what "other" means
  - Competitors: how it's different from Dialzara, Rosie, My AI Front Desk, Bland, Vapi
  - Owner alerts: email default, Telegram optional, what the summary contains
  - Data privacy: PIPEDA, CASL, two-party consent, call recordings
  - Cancel/refund policy: 30-day money-back, no contracts
- Verify `queryKnowledge` tool is registered and working for `unmissed-demo`
- Update demo prompt to reference knowledge base for product-specific answers

## Acceptance
- A demo caller can ask "how do I set this up on Rogers" and get a useful answer from knowledge, not prompt-dodge
- `queryKnowledge` returns results for product queries
- No prompt bloat — product details live in knowledge chunks, not in the 7.5K system prompt
