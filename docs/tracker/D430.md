# D430 — Personality Template System for Outbound Calls

## Summary
Outbound calling (dial-out, scheduled-callbacks) supports a single `outbound_prompt`. There's no way for clients to browse, preview, select, or customize outbound personalities. The "Busty Bodacious" personality prototype proved the concept works — a caller can hear a sassy assistant instead of a generic robot. But the product has zero dashboard UI for this.

## Required
- Design personality template schema: name, tone label, sample opening, target niche
- Dashboard component: browse personalities → preview → select per campaign
- Custom personality editor: goal, opening, tone, vm_script, call notes
- Store selected personality key in `campaign_leads` or `clients.outbound_prompt`
- Default personalities: Warm Professional, Direct, Busty Bodacious, Friendly Neighbour

## Acceptance
- Client can browse 3+ personality options from the dashboard
- Selecting a personality sets/assembles the `outbound_prompt`
- Custom personality can be saved for reuse
- Personality preview renders via a test call with that prompt
