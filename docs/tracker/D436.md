# D436 — Demo agent owner-alert + conversion-flow hardening

## Summary
The May 24 unmissed-demo test call sounded natural but exposed product gaps: the agent drifted from product demo into booking flow without a clean owner-summary reveal, accepted nonsense after offering an alternate time, and produced no Telegram owner alert because the demo client had no bot token configured. The call also failed classification/summary into UNKNOWN, so the owner never got a usable post-call card.

## Required
- Follow implementation plan: `docs/plans/2026-05-24-demo-stages-owner-alerts.md`.
- Ensure `unmissed-demo` has the same owner-alert path as real clients: Telegram bot token, chat ID, notification preference, and durable `notification_logs` rows.
- Add a demo-specific alert format that shows the business owner what would have been captured: caller type, pain/business, intent, booking/link action, summary, next step, and recording link when available.
- Repair demo classification fallback so a completed transcript never becomes only `UNKNOWN — check OpenRouter API key` without preserving a deterministic summary.
- Redesign the demo prompt flow around: answer question → identify business/pain → simulate missed-call capture → show owner summary/alert → send setup link or book walkthrough.
- Prevent the booking stage from treating off-topic/nonsense caller input as confirmation.
- Replace stale `unmissed.ai` spoken/link references with `endvoicemail.ai` on all demo surfaces.
- Add observability for demo conversion: demo call → SMS/link sent → booking created → checkout/client created, with IDs linked where possible.

## Acceptance
- A fresh `unmissed-demo` test call creates a Telegram `notification_logs` row with status `sent`.
- The owner receives a useful alert through the configured bot for non-JUNK demo calls.
- The agent does not book after irrelevant text like “you smell that?”; it asks a clarification or continues the demo safely.
- Demo transcript includes an explicit “here is what the owner gets” moment before conversion handoff.
- Demo conversion dashboard can show total demos, contacted leads, booked walkthroughs, SMS sent, and paid/trial conversions without manual Supabase queries.
